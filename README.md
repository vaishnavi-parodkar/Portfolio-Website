# 🌐 Portfolio Website

Welcome to my **personal portfolio website** — a place where I showcase my skills, projects, and experiences as a developer 🚀.  
It’s designed with a clean UI, responsive layout, and smooth navigation to give visitors a quick insight into who I am and what I build.  

---

## ✨ Features

- 📱 **Responsive Design** – Works across desktop, tablet, and mobile  
- 🎨 **Modern UI/UX** – Clean, minimal, and user-friendly interface  
- 💼 **Projects Showcase** – Highlights my work with descriptions & links  
- 📑 **Resume Section** – Easy access to my CV  
- 📬 **Contact Section** – Simple way to connect with me  

---

## 🛠️ Tech Stack

- **Frontend**: ReactJS, JavaScript, HTML5, CSS3  
- **Hosting**: Vercel

---

## ⚡ Getting Started

Follow these steps to run the project locally:

```bash
# Clone this repository
git clone https://github.com/vaishnavi-parodkar/Portfolio-Website.git

# Navigate into the project folder
cd Portfolio-Website

# Install dependencies
npm install

# Start the development server
npm run dev
```
